# B站深度阅读助手（Bilibili Digest）

把 B 站视频变成深度学习资源：一键提取字幕文稿、AI 生成概览、双语对照、时间戳笔记。完全中文界面，数据与 API Key 均只保存在本地。

> 灵感来自 [youtube-digest](https://github.com/zarazhangrui/youtube-digest)，但面向 B 站做了专门适配。

---

## 功能特性

| 功能 | 说明 |
|------|------|
| **字幕文稿** | 自动获取 B 站视频字幕（支持 UP 主上传 CC 字幕与 AI 生成字幕），按时间戳分段展示，点击即可跳转。 |
| **AI 概览** | 一键生成「一句话摘要 + 核心要点 + 章节划分 + 金句」。 |
| **双语/中文视图** | 非中文视频可逐段翻译为中文，支持原文 / 双语 / 中文三种视图。 |
| **AI 解释选中** | 在文稿中选中任意文字，让 AI 解释含义与背景。 |
| **时间戳笔记** | 记录当前播放时刻的笔记，时间戳可点击跳转；支持 AI 润色与导出 Markdown。 |
| **BYOK 自带密钥** | 使用你自己的 DeepSeek API Key，密钥仅保存在浏览器本地。 |
| **无字幕也能用 · 本地语音转写** | 没有字幕的视频，可用内置 Whisper 在浏览器内把语音转成文字（全程本地、不上传音频），再生成文稿与概览。 |

---

## 安装方法（Chrome / Edge / 任意 Chromium 浏览器）

1. 下载本扩展源码：解压 `bilibili-digest.zip` 到任意位置（例如桌面）。
2. 打开浏览器扩展管理页：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择 `bilibili-digest` 文件夹。
5. 安装成功后，浏览器右上角会出现扩展图标。

## 配置 API Key

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 并登录。
2. 创建一个新的 API Key（以 `sk-` 开头），复制备用。
3. 在浏览器地址栏右侧找到「拼图」图标（扩展管理按钮），点击后在弹出列表里找到「B站深度阅读」。
   - 如果列表里没有，说明扩展未正确加载，请回到[安装方法](#安装方法chromedge任意-chromium-浏览器)检查。
   - 建议点击扩展名称旁边的「图钉」图标将其固定到工具栏，以后直接点工具栏图标即可。
4. 点击「B站深度阅读」扩展图标，浏览器右侧会弹出侧边栏面板。
   - **前提**：当前标签页必须是一个 B 站视频页面（`www.bilibili.com/video/BV...`），否则侧边栏会显示空状态提示。
   - 如果点击后无反应，请确认浏览器版本为 Chrome 116+ 或 Edge 114+。
5. 在侧边栏顶部，「B站深度阅读」标题的右侧有一个齿轮图标，点击它。
   - 点击后会打开一个新的浏览器标签页，即设置页（不是在侧边栏里弹窗）。
6. 在设置页的「API Key」输入框中粘贴刚才复制的 Key，点击「保存设置」。
7. （可选）点击「测试连接」，如果显示「连接成功」说明配置完成，可以开始使用了。

> 默认使用 `deepseek-v4-flash` 模型，速度快、性价比高。如需更强推理可改为 `deepseek-v4-pro`。注意：旧模型名 `deepseek-chat` / `deepseek-reasoner` 已于 **2026-07-24 正式退役**，若你的扩展仍使用这两个名字会导致 AI 功能永久卡死或报错，请尽快切换。

## 使用指南

1. **打开 B 站视频页**：在浏览器中打开任意带字幕的 B 站视频，例如 `https://www.bilibili.com/video/BVxxxxxxxx`。
2. **打开侧边栏**：点击扩展图标，浏览器右侧会出现侧边栏。
3. **查看文稿**：切换到「文稿」标签，即可看到按时间戳分好的字幕文本。点击时间戳可跳转视频，工具栏可一键「导出文稿」为 Markdown（含译文）。
4. **生成 AI 概览**：切换到「概览」标签，点击「生成 AI 概览」，稍等片刻即可看到摘要、要点、章节和金句。生成后排栏可「导出」概览为 Markdown，并在「请求诊断」中查看本次 token 用量与费用估算。
5. **翻译非中文视频**：若视频字幕不是中文，可点击「翻译全文」生成中文译文，支持「原文 / 双语 / 中文」三种视图切换。
6. **记录笔记**：切换到「笔记」标签，点击「记录当前时刻笔记」会自动带上当前视频时间戳；填写内容后自动保存，支持 AI 润色与导出 Markdown。
7. **选中解释**：在「文稿」中选中一段文字，点击「解释选中」，AI 会结合上下文给出解释。

## 无字幕视频：本地语音转写（无需字幕也能总结）

很多 B 站视频没有字幕（UP 主未开「AI 字幕」、未上传 CC 字幕），这类视频原本无法生成文稿与概览。本扩展内置了**完全在本地的语音转写**（基于 Transformers.js + OpenAI Whisper），可以把视频声音转成文字，再走原有的 AI 概览流程。

**特点**
- ✅ **全程本地**：语音识别在浏览器内通过 WASM 完成，**音频不会上传到任何服务器**，隐私安全。
- ✅ **零额外配置**：不需要任何 API Key，也不需要联网（首次需联网下载约 40MB 的识别模型，之后会缓存在浏览器，再次使用秒开）。
- ⚠️ **实时录音**：受 B 站跨域限制，无法瞬间抓取音频文件，扩展会随视频播放**实时录音**（视频自动从头播放，请保持页面在前台、不要静音）。因此长视频的转写耗时≈视频时长（例如 40 分钟视频约需 40 分钟录音 + 几分钟本地推理）。这是本地方案的固有 tradeoff。
- ⚠️ **模型精度**：默认使用 `whisper-tiny`（最快，中文识别尚可）；如需更高精度可改 `whisper-worker.js` 中的模型为 `Xenova/whisper-base`（更准但更慢、模型更大）。

**使用步骤**
1. 打开一个**没有字幕**的 B 站视频，侧边栏「文稿」会提示「该视频没有可获取的字幕」，并出现一个蓝色按钮「🎙 本地语音转写（无需字幕）」；你也可以直接点工具栏的「🎙 语音转写」。
2. 点击后视频会自动从头播放并开始录音，进度条实时显示「已录音 / 总时长」。你可以等视频自然放完（会自动停止），也可以随时点「停止并转写」提前结束（会转写已录部分）。
3. 录音结束后，扩展自动把音频解码为 16kHz 单声道，交给本地 Whisper 转写，状态栏会显示「正在转写…」和实时片段文字。
4. 转写完成后，文稿标签页会自动填入带时间戳的转写文本（标注为「本地语音转写 (Whisper)」），此时再点「生成 AI 概览」即可像有字幕一样生成摘要、要点、章节与金句。

> 提示：转写质量取决于音质。背景音乐过大、多人同时说话、口音较重时识别率会下降，属正常现象。

## 常见问题

### 提示「该视频没有可用的字幕」怎么办？

这表示该视频没有获取到字幕。可能原因：

- UP 主没有开启「AI 字幕」功能，也没有上传 CC 字幕。
- 视频为会员专享、付费或地区受限，接口无法返回字幕。
- 浏览器未登录 B 站账号，部分接口需要登录态（请尝试先登录 B 站）。

解决方向：切换到其他有字幕的视频，或登录 B 站后重试。

### 是否需要登录 B 站？

- 大部分公开视频的字幕接口不强制登录即可获取。
- 部分视频会返回「需要登录」错误，此时请在当前浏览器登录 B 站账号后刷新页面。

### 为什么点击扩展图标没反应？

请确认浏览器为 **Chrome 116+** 或 **Edge 114+**，且已开启「开发者模式」并正确加载扩展。老版本浏览器不支持侧边栏（Side Panel）API。

### 是否可以离线使用？

- 字幕提取在本地完成（通过 B 站公开接口）。
- AI 概览、翻译、解释、润色等功能需要联网调用 DeepSeek API。

### 我的 API Key 会被上传到你们的服务器吗？

不会。API Key 仅保存在浏览器的 `chrome.storage.local` 中，所有 AI 请求都直接从你的浏览器发往 DeepSeek。

### 扩展管理页提示「Service Worker（无效）」怎么办？

先说结论：这通常**不是代码问题**，而是扩展的「后台服务」处于坏状态或加载路径不对。按下面顺序排查：

**① 确认加载的是正确的文件夹（最常见原因）**
- 解压 zip 后，文件夹结构应是 `bilibili-digest/`，里面**直接**包含 `manifest.json`、`background.js`、`sidepanel.html` 等。
- 在 `chrome://extensions/` 点「加载已解压的扩展程序」时，**必须选中这个 `bilibili-digest` 文件夹本身**，而不是它的父目录、也不是 zip 文件。
- 如果解压出来是 `bilibili-digest/bilibili-digest/...`（双层嵌套），请进入内层那个 `bilibili-digest` 再加载。

**② 彻底重载（清掉旧版残留的坏状态）**
1. 在 `chrome://extensions/` 找到「B站深度阅读助手」，点**移除**（彻底删掉）。
2. 重新点「加载已解压的扩展程序」，选中正确的 `bilibili-digest` 文件夹。
3. 重新打开 B 站视频页刷新（F5）。

**③ 看真实报错（仍不行时）**
- 在扩展卡片上，点「Service Worker（无效）」文字右侧的 **「错误」按钮**，或点「检查视图：Service Worker」打开后台控制台。
- 把里面的红色报错文字截图发我，即可精准定位。

> 小提示：本扩展的后台脚本已加全局错误捕获。如果后台真有运行时错误，控制台会打印 `[B站深度阅读] SW 运行时错误：…` 或 `SW 未处理的 Promise 拒绝：…`，据此即可判断。
